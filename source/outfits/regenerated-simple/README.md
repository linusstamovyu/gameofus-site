# Regenerated outfit sheets

Single handoff set for the Game of Us website: 30 transparent 1152×256 nine-frame walk sheets (Rico, Kai, Ethan, Nala, Elias, and Coco across ski, neon, jungle, fairy, and Mars).

Every sheet was regenerated with Image Generator. Each prompt locked the character's original walk sheet for identity, hair, face, gait, and registration; it used the themed outfit reference only for wardrobe; and it used Rico's runtime walk sheet for the polished Ruby/GBA rendering grammar. Only the outfit changes.
